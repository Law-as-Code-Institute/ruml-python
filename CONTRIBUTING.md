# Contributing

This repository holds the Python parser for RUML. It is published by the
Law as Code Institut GmbH; Rulemapping Group GmbH holds the rights.

## What we take at the moment

Feedback is welcome. Please open an issue for

- errors, gaps and unclear passages,
- questions about how something is meant,
- proposals for changes or additions.

We do not accept pull requests yet. In this first phase the repository is an export of
our internal sources: each commit here is one export, and a change made here would be
overwritten by the next one. If an issue leads to a change, we make it in the sources and it
arrives here with the next export.

We will open the repository for code contributions later and describe the process here.

## Security

Please do not report security problems in a public issue. Use "Report a vulnerability" in the
Security tab of this repository.
